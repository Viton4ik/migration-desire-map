Countries People Want to LEAVE vs MOVE TO - stage 4 visual test (10 s, silent, 3 countries)

OPEN
  The page loads local files, so serve the folder over HTTP (browsers block file:// fetches):
    cd stage4 && python3 -m http.server 8000   -> open http://localhost:8000/index.html
  Controls: Play/Pause, Replay, time slider, check selector (status set + technical checks). ?render=1 hides controls.

WHAT CHANGED vs the LOVE/HATE engine (engine/ template)
  statuses      6 value bands from project_brief.txt, diverging colours: MAGNET (green, magnet), MORE WANT IN (light green,
                arrow in), MOST STAY (grey-blue, house), MANY WANT OUT (orange, door arrow), MOST WANT OUT (red, departing plane),
                CAN'T LEAVE (purple, padlock). 3D icons drawn in code (statusIcon).
  map colour    a visited country is filled with its flag; when the camera leaves its shot the flag fades to the status colour
                (E.colorAfter), so the world map slowly becomes the answer (green = want in, red = want out).
  data quality  quality G = Gallup (plain), S = other survey (dashed black/white outline + OTHER SURVEY badge on the card),
                E = UN estimate (white hatching on the map, hatched UN ESTIMATE badge, hatched chip header).
  number chip   ev.kind 'num': header (source + years), big number, meaning line, status icon; colour = status colour.
  card / list   pill = status label + the number and its year (no repeated words); recent list uses a short tag (rtag).
  intro         suitcase emblem (assets/theme_suitcase.png, drawn in code: assets/theme_suitcase_source.html -> render/emblem.js)
                + "COUNTRIES PEOPLE WANT TO" + LEAVE vs MOVE TO pills.
  subject       none (E.subject = null): no country is pre-filled.
  tech checks   picked automatically from countries.csv + world.js by tools/build_test_episode.py.

STRUCTURE
  index.html                    engine: drawFrame(t) is a pure function of time
  data/episode.js               GENERATED by tools/build_test_episode.py (test only; stage 5 uses tools/build_episode.py + real WAV)
  data/world.js                 Natural Earth 1:10m borders, pre-projected (data/prep_world.mjs)
  assets/flags/*.svg            159 flags incl. gm.svg, sz.svg added from svg-country-flags 1.2.10 (public domain)
  assets/fonts/                 Lilita One, Nunito (SIL OFL)
  assets/theme_suitcase.png     emblem
  render/render.js              node render/render.js video out.mp4 [t0 t1] | chunk out.mp4 n0 n1 | frames dir t1,t2 | tech dir
  render/emblem.js              rebuilds the emblem PNG
  export/                       test_10s_silent.mp4, test_10s_with_sound.mp4 (stack check), joined_2parts.mp4
  frames/full, frames/w640      control frames; frames/tech technical checks

DETERMINISM
  Same t -> same frame. Randomness from mulberry32(seed 20261104). Clouds anchored in world space at init, only over sea.
